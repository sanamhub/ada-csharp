THIRD-PARTY NOTICES
===================

This package redistributes native binaries built from third-party source.


1. Ada URL parser  (ada-url/ada)
--------------------------------
Upstream:  https://github.com/ada-url/ada
Version:   v4.0.0 (pinned; see Directory.Build.props / AdaUrlUpstreamTag)
License:   Apache-2.0 OR MIT  (dual-licensed; this project relies on the MIT option)

The files runtimes/<rid>/native/ada.dll, libada.so and libada.dylib in this package
are compiled from unmodified Ada v4.0.0 sources. Build flags and CMake invocations are
recorded in native/ and in docs/ADA_PLAN.md section 2.

Full license text: https://github.com/ada-url/ada/blob/v4.0.0/LICENSE-MIT


2. simdutf  (simdutf/simdutf)
-----------------------------
NOT INCLUDED. Ada is built with ADA_USE_SIMDUTF=OFF, so no simdutf code ships in this
package. Recorded here because the option exists upstream and was evaluated and rejected;
see docs/adr/0003-native-build-and-distribution-strategy.md for the reasoning.


SBOM
----
A CycloneDX SBOM is published with every release. It lists the managed dependencies and
every shipped native binary, each carrying the SHA-256 that matches native/CHECKSUMS.txt,
so a scanner sees the compiled library rather than only the NuGet graph.
